# DataTwist Error Codes

This document provides a comprehensive reference for all error codes generated by the DataTwist language. Each error includes its code, category, description, and actionable hint to help diagnose and fix issues.

Error codes follow the format `DT-XNNN` where `X` is a category prefix and `NNN` is a number:
- **DT-P**: Parse errors and syntax issues
- **DT-T**: Type errors
- **DT-R**: Runtime errors
- **DT-D**: Data warnings
- **DT-C**: Connection errors

---

## Parse Errors (DT-P001–P009)

Core syntax parsing failures. These occur during the initial parsing phase before code execution.

| Code | Category | Description | Hint |
|------|----------|-------------|------|
| DT-P001 | PARSE ERROR | I could not parse this expression. | Check the syntax near the error location. |
| DT-P002 | PARSE ERROR | Unexpected end of expression after operator. | Add the missing right-hand side of the expression. |
| DT-P003 | PARSE ERROR | Unclosed string literal — missing closing `"`. | Add a closing double-quote to terminate the string. |
| DT-P004 | PARSE ERROR | Unclosed object — missing closing `}`. | Add a closing brace `}` to terminate the object literal. |
| DT-P005 | PARSE ERROR | Unclosed list — missing closing `]`. | Add a closing bracket `]` to terminate the list literal. |
| DT-P006 | PARSE ERROR | Missing `->` in guard branch. | Each guard branch needs an arrow: `\| condition -> result` |
| DT-P007 | PARSE ERROR | Missing expression after `\|>`. | Add a function or expression after the pipe operator. |
| DT-P008 | PARSE ERROR | Unexpected `\|>` — did you mean to write a function? | Remove the extra `\|>` or add a function between them. |
| DT-P009 | PARSE ERROR | Missing `->` in function definition. | Function syntax is `[params -> body]`. |

## Pattern Errors (DT-P010, DT-P013)

Errors specific to pattern matching syntax (the `#p"..."` pattern strings).

| Code | Category | Description | Hint |
|------|----------|-------------|------|
| DT-P010 | PATTERN ERROR | Adjacent unconstrained captures in `#p` pattern. | Add a literal separator between captures, or use type hints (`:d`, `:w`, `:N`, `:Nd`). |
| DT-P013 | PATTERN ERROR | Unrecognised type hint in `#p` pattern. | Valid hints: `:d` (digits), `:w` (word chars), `:N` (N chars), `:Nd` (N digits). |

## Common Mistakes (DT-P020–P026)

DataTwist syntax differs from other languages. These errors catch frequent mistakes when switching from other programming languages.

| Code | Category | Description | Hint |
|------|----------|-------------|------|
| DT-P020 | COMMON MISTAKE | DataTwist uses `is` for assignment, not `=`. | Write `x is 42` instead of `x = 42`. |
| DT-P021 | COMMON MISTAKE | DataTwist uses `is` for assignment, not `:=`. | Write `x is 42` instead of `x := 42`. |
| DT-P022 | COMMON MISTAKE | Use `->` not `=>` in function definitions. | Write `[x -> x * 2]` instead of `[x => x * 2]`. |
| DT-P023 | COMMON MISTAKE | Use `and` instead of `&&`. | Write `x > 5 and y < 10` instead of `x > 5 && y < 10`. |
| DT-P024 | COMMON MISTAKE | Use `not` instead of `!`. | Write `not active` instead of `!active`. |
| DT-P025 | COMMON MISTAKE | DataTwist uses spaces, not commas, to separate list items. | Write `[1 2 3]` instead of `[1, 2, 3]`. |
| DT-P026 | COMMON MISTAKE | DataTwist uses spaces, not commas, between object fields. | Write `{k: v k2: v2}` instead of `{k: v, k2: v2}`. |

## Type Errors (DT-T001–T003)

Errors that occur when operations are applied to values of incompatible types.

| Code | Category | Description | Hint |
|------|----------|-------------|------|
| DT-T001 | TYPE MISMATCH | Arithmetic operator used on incompatible types. | Arithmetic operators work on numbers (or `+` on strings). Check your types. |
| DT-T002 | TYPE MISMATCH | Comparison operator used on incompatible types. | Comparison operators require compatible types (both numbers or both strings). |
| DT-T003 | ARITHMETIC ERROR | Division by zero. | Check that the divisor is not zero before dividing. |

---

## Runtime Errors (DT-R001–R010, DT-R020, DT-R030)

Errors that occur during code execution after successful parsing.

| Code | Category | Description | Hint |
|------|----------|-------------|------|
| DT-R001 | UNDEFINED IDENTIFIER | The identifier is not defined. | Check the spelling or define the value with `is`. |
| DT-R002 | RUNTIME ERROR | Pipeline step is not a function. | Each step in a pipeline must be a function or expression that takes a value. |
| DT-R003 | RUNTIME ERROR | Cannot call nil as a function. | Check that the function value is defined and not nil. |
| DT-R004 | RUNTIME ERROR | Value is not callable. | Only functions can be called. Check the value type. |
| DT-R005 | ARITY ERROR | No matching arity for this function call. | Check the number of arguments you are passing. |
| DT-R006 | DESTRUCTURING ERROR | Cannot destructure a non-object value. | Object destructuring (`{field}`) requires the value to be an object. |
| DT-R010 | TYPE MISMATCH | Collection operation applied to non-collection. | `filter` and `map` expect a list. Check the type of the value being piped. |
| DT-R020 | NIL ERROR | Nil value where a value was required. | A nil propagated through an operation that requires a non-nil value. |
| DT-R030 | CONFIG ERROR | Unknown system constant. | Valid constants: `SAMPLE_SIZE`, `DESCRIBE_SAMPLE_SIZE`, `PRINT_WIDTH`, `MAX_COLLECT_ROWS`. |

---

## Data Warnings (DT-D001–D003)

Non-fatal warnings that indicate unexpected or potentially problematic data conditions.

| Code | Category | Description | Hint |
|------|----------|-------------|------|
| DT-D001 | DATA WARNING | Nil values encountered in map step. | Some rows had nil at the accessed path. Results may contain nil. |
| DT-D002 | DATA WARNING | Nil sort keys encountered. | Rows with nil sort keys were sorted to the end. |
| DT-D003 | DATA WARNING | Nil group keys encountered. | Rows with nil group keys were grouped under nil. |

---

## Connection Errors (DT-C001–C002)

Errors related to external resource access (files, databases, network).

| Code | Category | Description | Hint |
|------|----------|-------------|------|
| DT-C001 | FILE NOT FOUND | File not found. | Check the file path and make sure the file exists. |
| DT-C002 | CONNECTION ERROR | Database connection failed. | Check that the database is running and the URI is correct. |

---

## Error Handling

All DataTwist errors are structured as exception maps with the canonical shape:

```clojure
{:dt/error   true                  ; marker — distinguishes DT errors
 :code       "DT-T001"             ; error code
 :category   "TYPE MISMATCH"       ; ALL CAPS category
 :message    "I can't add..."      ; first-person prose message
 :source     "\"hello\" + 5"       ; offending source line(s)
 :line       1                     ; 1-based line number (optional)
 :col-start  1                     ; 1-based column start (optional)
 :col-end    14                    ; 1-based column end (optional)
 :hint       "Try ..."             ; optional actionable suggestion
 :level      :error                ; :error or :warning
}
```
